# SaathMein Web

Next.js (App Router) app for the **dealer dashboard** (`/seller`) and the **Owner / Admin Console** (`/admin`), plus the public landing page.

```bash
cp .env.example .env.local   # then fill in values
npm install
npm run dev                  # http://localhost:3000
npm run lint
npm run build
```

Design tokens: `src/styles/tokens.css` (Sunrise theme, PRD §14.1). Project rules: see the root `CLAUDE.md`.
